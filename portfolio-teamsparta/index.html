CASE 01

세일즈 콜 기준으로 인플루언서 가이드를 재구성해 구매 전환율을 1.7배로 높인 경험

링글 틴즈 | 2024.07 ~ 2024.12
릴스 광고랜딩 유입가입구매

  1. ①팀 KPI

    • 프로젝트 목적: 인플루언서 광고의 구매 전환 증진
    • 팀 KPI: 가입당 비용 목표치와 적정 범위, 가입 → 첫결제 전환율 11%, 첫결제 ROAS 240%
    • 개선 전 가이드 광고의 가입당 비용은 적정 범위 이내로 KPI상 이상 징후 없음

  2. ②퍼널 이탈 지점

    • 광고비의 1/3을 편성한 인플루언서 광고에서 가입은 늘었지만 구매로 이어지지 않음
    • 가입 → 구매 4.8%는 팀 내부 기준 11%의 절반 이하, ROAS 63%는 기준치 240%는 물론 손익분기 100%에도 미달

  3. ③원인 분석

    • 세일즈 콜을 활용한 고객 리서치 실시: 영어 학습 목적, 유입 광고, 중시 요소를 질문해 학부모의 구매 결정 요인이 진도와 첨삭임을 확인
    • 성과 상위 4개와 하위 4개 영상 요소별 비교 분석 실시: 고성과 영상에는 예습, 수업, 숙제, 복습의 4단계 학습 과정이 노출됨

  4. ④문제 정의

    왜 학부모가 보는 기준이 콘텐츠에 없었나

    • 개선 전 가이드는 '재미있게, 많이 말하기'만 요구해 학부모의 구매 결정 요인인 진도와 첨삭이 콘텐츠에 없었음
    • 엄마표 영어, 영유 자녀, 사립초 자녀, 국제학교 자녀, 미국 학교 진학 준비 등 자녀 배경이 다른 인플루언서에게 같은 흐름을 요구해 각 타겟 학부모에게 맞는 소구가 되지 않음
가설

학부모의 기준인 예습, 수업, 숙제, 복습의 4단계 학습 과정과 튜터 첨삭이 보이도록 가이드를 재구성하고, 인플루언서 유형별로 도입부와 강조점을 나누면 구매 전환이 오를 것

CASE 02

상담 기록 163건에서 찾은 기준으로 소재와 판정 기준을 바꿔 예약률을 3배로 끌어올린 경험

이지엠앤씨 | 2026.07 ~ 2026.09
광고상담 신청CS 통화예약내원

  1. ①팀 KPI

    • 프로젝트 목적: 임플란트 상담 신청의 예약과 내원 증진
    • 팀 KPI: 임플란트 상담 신청 DB 단가. 명시된 목표치 없이 직전 달 수준 유지와 소재 간 상대 비교로 판정
    • 광고 성과를 DB 단가로 판정해 소재와 랜딩의 ON/OFF와 예산 배분을 결정하는 구조. 이 기준에서는 지원금 소구가 최우수로 분류됨. 구글 기준 지원금 랜딩의 DB 단가가 가격 공개 랜딩보다 32% 낮았기 때문

  2. ②퍼널 이탈 지점

    • 7월보다 광고비와 상담 신청은 늘었고 DB 단가는 28% 악화에 그쳐 보였지만, 8월 초 계정 전체 예약률은 10.3%에서 3.5%로 3분의 1 수준까지 하락하고 예약단가는 3.7배 상승

  3. ③원인 분석

    • 상담 기록 163건 전수 분석: 혜택만 보고 신청한 허수가 8월 초 신청의 절반인 50.5%
    • 지원금 안내 랜딩은 '신청한 적 없다' 응답이 11.2%, 가격 공개 랜딩은 0.9%
    • 광고로 재유입됐지만 기존 환자로 분류돼 광고 성과에서 누락되던 예약과 내원을 광고 리드 DB와 매칭해 집계, 광고 성과가 실제보다 낮게 잡히던 왜곡을 보정

  4. ④문제 정의

    왜 신청은 늘고 예약은 무너졌나

    • 광고 성과를 DB 단가로 판정해 소재 ON/OFF를 결정하니, 지원금 소구 소재가 계속 ON으로 유지됐고 시 지원금으로 오인한 허수 신청이 늘어도 판정에 드러나지 않았음
    • 임플란트는 의료진과 가격을 보고 결정하는데 광고는 둘 다 보여 주지 않았음
가설

신청 전에 핵심 USP인 의료진 이력과 가격을 보여 주면 허수는 줄고 예약은 늘 것검증은 같은 기간 기존 소재와 허수, 예약, 내원 비교
